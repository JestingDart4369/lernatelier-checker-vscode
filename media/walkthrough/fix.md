# Fehler beheben

- **Rot**: Pflichtangaben fehlen oder ein fälliger Tag ist unvollständig.
- **Gelb**: Wortzahlen oder Formate passen nicht ganz.
- **Grün** (✓ im Explorer): alles in Ordnung.

Steht der Cursor auf einer markierten Stelle, zeigt die Glühbirne Korrekturen: Namen eintragen, Zeitraum übernehmen, fehlende Tage einfügen und mehr. Auf einer Tages-Überschrift bietet sie an, offene Arbeitspakete vom Vortag zu übernehmen.

**Bericht anzeigen** schreibt alle Punkte ins Ausgabefenster.
